# คลัง Prompt ตั้งต้นสำหรับงานวิจัย

สร้างใน LibreChat: เมนูข้าง **Prompts → Create Prompt** ใส่ชื่อ, Category, Command (พิมพ์ `/` ตามด้วยชื่อในช่องแชทเพื่อเรียกใช้)
และข้อความด้านล่าง แล้ว **Share** ให้ทุกคน คำใน `{{...}}` LibreChat จะถามผู้ใช้ก่อนส่ง

ผู้ใช้ที่มี prompt ที่ได้ผลดี แชร์เข้าคลังได้แบบเดียวกัน ทีมดูแลคัดและปรับทุกเดือน (ดู `README.md`)

---

## 1. ทบทวนวรรณกรรมจากไฟล์ที่แนบ — `/litmatrix`

Category: Research

```
อ่านงานวิจัยที่แนบมาทั้งหมด แล้วทำตารางสังเคราะห์วรรณกรรม (literature matrix) เป็นไฟล์ Excel คอลัมน์: ผู้แต่ง (ปี), ประเด็นที่ศึกษา, ทฤษฎี/กรอบแนวคิด, ตัวแปร, กลุ่มตัวอย่างและบริบท, วิธีวิจัย, ผลการวิจัยหลัก, ข้อจำกัด/ช่องว่าง
จากนั้นสรุปในแชท 3–5 ย่อหน้า: ข้อค้นพบที่สอดคล้องกัน, ข้อขัดแย้ง, และช่องว่างงานวิจัยที่เกี่ยวกับหัวข้อ {{หัวข้อวิจัยของฉัน}}
ใช้เฉพาะข้อมูลจากไฟล์ที่แนบ ถ้าไฟล์ไหนไม่มีข้อมูลในคอลัมน์ใด ให้เขียนว่า "ไม่ระบุ"
```

```

แสดงฉบับปรับแล้ว ตามด้วยตารางการเปลี่ยนแปลงที่สำคัญ (เดิม → ใหม่ → เหตุผล) ไม่เกิน 8 แถว

{{ข้อความ}}
```

## 3. ตรวจความสอดคล้องของงานวิจัย — `/alignment`

```
ตรวจความสอดคล้องระหว่าง ชื่อเรื่อง, คำถามวิจัย, วัตถุประสงค์, สมมติฐาน, กรอบแนวคิด, วิธีวิจัย และสถิติที่ใช้ ของงานวิจัยต่อไปนี้
ทำเป็นตาราง alignment matrix (แต่ละวัตถุประสงค์ ↔ คำถาม ↔ สมมติฐาน ↔ ตัวแปร ↔ เครื่องมือ ↔ การวิเคราะห์) ระบุจุดที่ไม่สอดคล้องและเสนอวิธีแก้ที่เปลี่ยนน้อยที่สุด

{{รายละเอียดงานวิจัย}}
```

## 4. ออกแบบแบบสอบถาม — `/questionnaire`

```
ออกแบบแบบสอบถามสำหรับวัดตัวแปร {{ตัวแปร/โครงสร้าง (constructs)}} กับกลุ่มเป้าหมาย {{กลุ่มเป้าหมาย}}
- เสนอข้อคำถามแต่ละตัวแปร 4–6 ข้อ อ้างอิงแนวคิด/มาตรวัดที่มีอยู่ (ระบุว่าต้องตรวจสอบแหล่งที่มา) มาตรวัดลิเคิร์ต 5 ระดับ
- ทำไฟล์ Excel 2 แผ่น: (1) ข้อคำถาม พร้อมรหัสตัวแปร (2) แบบประเมิน IOC สำหรับผู้เชี่ยวชาญ 3 ท่าน พร้อมสูตรคำนวณค่า IOC
- บอกขั้นตอนตรวจความเที่ยง (Cronbach's alpha) และความตรงที่ควรทำ
```

## 10. แผนเก็บข้อมูลและจริยธรรม — `/ethics`

```
งานวิจัยของฉัน: {{สรุปงานวิจัย กลุ่มตัวอย่าง วิธีเก็บข้อมูล}}

ระบุว่าส่วนใดต้องตรวจสอบกับแบบฟอร์มจริงของคณะกรรมการจริยธรรมการวิจัยของหน่วยงาน
```
